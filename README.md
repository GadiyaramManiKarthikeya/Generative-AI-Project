#  AI Fashion Designer – Generative AI Project

This project uses Python + Streamlit to generate AI-based fashion designs, style ideas, and outfit recommendations.

## Features
- AI-generated outfit ideas
- Color and pattern suggestions
- Fabric and style combinations
- Easy to run in Streamlit Cloud

## How to Run Online
1. Upload this project to GitHub
2. Open Streamlit Cloud
3. Select "Deploy App"
4. Paste GitHub repo link
5. Select `app.py` and deploy

## Technologies Used
- Streamlit (Frontend Web App)
- Python (Logic)
